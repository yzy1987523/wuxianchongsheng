
# 第四部分：AVG 五章主线剧本（含剧情、分支、对话选项，视位解锁控制）

> 规则：视位决定可解锁选项、线索、NPC信任度。视位通过轮回经历、收集档案、见证事件提升。轮回代价：精神负荷。高轮回后出现【沉沦倾向】选项，提升精神负荷，影响结局判定。

## 第1章：低语先兆（视位L1解锁）

**轮回起点：广播前72小时**

**剧情梗概**：主角醒来，携带着上一轮轮回残留记忆。城市表面一切如常，但空气中弥散隐约的认知低语。玩家拥有三个初始调查方向：追踪使徒外围据点 / 前往序调组临时办公点 / 在居民区走访收集异常传闻。序调组此时正在筹备突袭使徒据点，定性对方为邪教团伙，完全不理解广播的真实危害。序调组队伍内部已经存在隐性使徒化人员，伏笔埋藏在队员神态、对话细节之中。

**固定主线事件**：无论开局如何选择，本章末尾获知：使徒计划72小时后启动全球广播。序调组仅认为这是大型线上邪教宣讲，不相信广播会造成全域认知侵染。倒计时归零，广播启动，城市零星出现狂暴畸变伤人事件，第一章结束。若玩家在广播前死亡，轮回重置，视位保留回到起点。

### 分支选项

**分支A：前往序调组临时办公点，对话对象：林砚**

- 说明情报：这次宣讲不是普通宣传，会造成大规模认知污染。
  林砚反应：高度警惕，登记你为可疑人员，记录证词，但内部判定你受邪教素材影响产生妄想。序调组突袭计划不变。视位小幅\+1。
- 只提供使徒据点地址，不多解释广播危害。
  林砚反应：感谢情报，外勤调整布控，突袭伤亡小幅降低。视位微量\+1。
- 隐瞒情报，离开办公点。
  林砚继续原有计划，突袭行动伤亡更高。视位无变化。

**分支B：潜入使徒外围集会点，对话对象：使徒外围宣讲者**

- 假意认同理念，套取广播载体细节。解锁第3章隐藏选项。精神负荷轻微上升。
- 直接质问广播带来的灾难。触发冲突，被迫战斗或撤离。
- 安静听完，悄然离开。了解使徒核心诉求：人类认知被世俗枷锁禁锢，畸变是通往更高真实的通道。

**分支C：居民区走访**

收集普通市民口述：失眠、耳边持续微弱低语、看到光影扭曲。解锁档案【早期个案笔录】。本章以线索收集为主，战斗极少。

## 第2章：喧嚣初崩（视位L2解锁）

**剧情梗概**：广播已经落地。城市秩序初步撕裂。狂暴畸变体伤人事件陆续爆发，医院、派出所被报案淹没。序调组外勤奔赴现场处置，伤亡开始出现。队员在污染现场开始感知低语，部分人员出现感知异常。序调组内部隐性同化人员大规模苏醒，信任危机开始显现。本章主角初次遇见陈野，此时陈野只是普通外勤，在处置狂暴畸变体现场暴露于认知污染环境。

核心认知：狂暴畸变体可以被枪械轻松击倒，序调组真正的威胁不是怪物，是内部人员的缓慢认知偏移。

**主线固定事件**：序调组处置现场遭遇失控狂暴畸变体，队员重伤。陈野近距离接触污染源，第一次感知到自身认知被畸变低语侵蚀，展现出极强的认知抵抗能力。苏清开始整理资料，着手草拟《序调组思维隔离守则》。

### 分支选择：场景：畸变现场，主角与陈野相遇

- 提醒陈野：你已经被污染侵染，不要主动深究畸变传递的启示，尽量减少长时间停留在污染环境。
  陈野：半信半疑，记下警告，后续接触污染源时刻意克制，污染积淀增长变慢。解锁陈野专属长期剧情分支。视位\+1。
- 保持沉默，旁观陈野自主应对。
  陈野在危机下直面污染低语，污染积淀上涨，沉沦倒计时加快。
- 【L2解锁】告知陈野自我思维锚定的方法。
  陈野掌握心智防护技巧，高危作业耐受提升，但会更频繁进入污染现场，长期污染总量上升。精神负荷上升。

### 本章三大走向分支

1. 协助序调组现场封控：序调组保全更多外勤队员，后续扩编保留更多骨干。
2. 优先追踪使徒线索：序调组人手不足，现场伤亡增多，但获取使徒核心据点情报。
3. 优先救助平民：获得平民信任，但序调组外勤对你信任度下降，认为你脱离核心危机。

**本章收尾**：序调组高层确认事件远超普通邪教暴乱，向上级申请紧急增调各部门精英人员，序调组进入大规模扩编阶段。第二章结束。

## 第3章：饮鸩之力（视位L3解锁）

**剧情梗概**：广播后两周。序调组完成扩编。陈野正式成为序调组第一位抗性级人员。序调组内部争论白热化：是否继续派遣抗性人员进入高危污染现场。苏清完成《序调组思维隔离守则》初稿，落地执行人员三级分级管理制度。序调组缴获大量使徒污染卷宗，通过卷宗初步总结认知污染四阶段模型，但依旧不了解畸变的高维本源。使徒势力在暗处吸纳新的求知畸变者。

**主线固定事件**：序调组计划安排陈野带队突袭使徒一处存放大量污染素材的仓库。仓库内高浓度认知污染，长时间停留会快速加重认知偏移。

### 分支选择：场景：突袭行动前，序调组临时指挥所

- 劝说保守派高层：封存仓库素材，禁止队员进入仓库接触污染源。
  突袭改为远程封锁。陈野无需高强度暴露在污染环境，积淀增长放缓。仓库素材没有销毁，后续使徒会取回复用。
- 支持务实派，允许陈野带队突袭，但严格限制接触素材时长。
  仓库污染素材被销毁。陈野必须长时间暴露在污染环境，污染积淀明显上涨。序调组获得大量使徒卷宗，研究进度加快。
- 【L3限定选项】玩家独自潜入仓库销毁素材，不让序调组队员进入。
  玩家独自行动，战斗难度升高。序调组无人员污染新增。主角精神负荷大幅上升。

### 陈野命运分支联动

- 前两章持续提醒陈野规避污染：陈野外化畸变症状轻微，坚守时间更长。
- 多次鼓励陈野深入污染现场：陈野更早出现皮肤纹路、瞳孔异变，沉沦倒计时缩短。

**本章收尾**：序调组落实全员心理筛查、分级管控。序调组人员不断有人被检出认知偏移，或转入浅染级，或直接被判定隐性同化隔离。第三章结束。

## 第4章：真理与代价（视位L4解锁）

**剧情梗概**：广播后一个月。序调组抗性人员数量缓慢增加，但所有人的污染积淀都在持续上涨。不断有浅染人员升级、抗性人员认知失守。部分人员隐性使徒化，秘密向使徒传递情报。使徒首领默言主动邀约主角会面。本章玩家彻底理解使徒底层逻辑：打不过枪械武装，所以选择同化秩序内部的人。

玩家可以选择与默言谈判、突袭默言据点，或是将默言的情报提交给序调组。同时玩家可以选择是否把轮回得到的完整畸变底层真相交付苏清。

### 分支选择：场景：默言会面地点

- 完整倾听默言理念。解锁完整世界观背景。精神负荷大幅上升，解锁结局1前置条件。
- 假意谈判，把默言据点坐标交给序调组，发起联合围剿。
  序调组集结力量发起进攻，重创使徒骨干，序调组外勤伤亡惨重。陈野大概率在本次作战中污染急剧加重，濒临认知失守。
- 直接发起对抗。默言撤退。使徒势力仅受损，根基保留。

### 序调组科研分支

- 将轮回得到的完整畸变底层真相交付苏清：序调组对污染理解飞跃，完善《思维隔离守则》，为结局2【守界余烬】提供核心条件。
- 隐瞒全部真相：序调组只能依靠牺牲缓慢摸索规律，世界走向接近原生线的沉沦结局。

**本章收尾**：各方底牌全部摊开，世界走向来到三岔路口。第四章结束，进入终章。

## 第5章：视位抉择（终章，L4视位解锁全部结局）

> 结局判定：综合视位、累计精神负荷、前面所有关键NPC选择、是否完善序调组隔离守则。

### 结局1：浊世孤敌（沉沦结局）

**触发条件**：轮回次数多，精神负荷超限；看透全部真相，但对人类反复的挣扎感到倦怠麻木；不协助序调组完善隔离体系，拒绝斩断畸变源头。

**剧情**：你清楚枪械可以杀死畸变躯体，但认知污染无法靠武力根除。序调组不断被内部同化侵蚀，组织持续瓦解。使徒缓慢渗透社会每一层面。世界走向慢性沉沦。你保留轮回能力，独自作为全知旁观者，一遍一遍目睹悲剧循环。

**关键词**：倦怠，旁观，放弃救赎。

### 结局2：守界余烬（制衡结局）

**触发条件**：视位满值，精神负荷可控；将轮回获得的完整认知污染机理交付苏清；在关键节点保护陈野，减少抗性人员不必要的污染暴露，完善《序调组思维隔离守则》。

**剧情**：序调组升级整套认知防护体系，严格管控高危污染作业、落实心理锚定训练、分级隔离人员。认知污染无法彻底根除，但扩散速度被无限延缓。序调组从临时工作组转为长期守望机构。人类获得漫长、脆弱的喘息时间，文明得以延续。

**关键词**：制衡，守望，延缓沉沦。

### 结局3：绝地天通（献祭结局）

**触发条件**：视位满值，精神负荷可控；掌握畸变本源真相；选择直面高维认知源头，以身切断畸变对外投放认知污染的通道。

**剧情**：主角依靠无数轮回淬炼的意志，进入畸变本源维度，切断高维认知污染持续输入现实世界的通道。新的认知种子无法再植入人体。已经存在污染积淀的人不会立刻痊愈，但污染不再继续增长，不会新增兽化、同化案例。使徒失去力量源头。序调组使命终结。主角献祭自身，轮回永久停止。

**关键词**：牺牲，斩断根源，终极救赎。

# 第五部分：可收集文档 ·《序调组思维隔离守则》（游戏内可拾取）

**文档类型**：内部保密规章｜编号：SOE\-001

**拟定人**：苏清（社会秩序应急调研组，精神卫生方向研究员）

**适用人员**：所有进入污染区域、接触畸变素材的序调组成员

**文档备注**：本守则无法根除认知污染，仅用于延缓认知偏移，降低隐性同化概率。不存在绝对安全。

**分发说明**：纸质版本单独存放，禁止拍照、扫描、转发电子版；每次进入高危现场前，必须通读一遍；高危岗位人员每日早会朗读核心条款，作为思维锚定。

## 前置警示（必读）

认知污染不以物理接触为必要条件。图像、音频、文字、现场残留的认知低语，都能缓慢改变人的底层认知。

污染不会立刻让人发疯。最危险的阶段，是你**自我感觉变得通透、平和、理解"另一种真实"**——这正是同化的开端。

制式枪械可以击杀畸变躯体，但无法阻挡思维层面的渗透。本守则是我们唯一的软性防线。

## 第一部分：作业行为守则（现场、素材库房通用）

1. 进入标定污染区域，必须双人编组，禁止单人长时间停留。设置硬性时间上限，到点强制轮换撤离，无论任务是否完成。
2. 所有畸变素材（图片、录音、手稿、视频、现场采集的笔录）统一存入双层隔离库房。查阅必须两人在场，限时阅览，禁止摘抄、私自备份、留存副本。
3. 阅览污染素材时，禁止长时间凝视画面、反复循环播放音频。一旦出现头晕、耳边低语、感知扭曲，立刻终止阅览，离开污染环境并上报。
4. 现场采集物证优先物理封装，不要反复回看、复盘现场记录。只提取办案必需信息，禁止出于好奇研究素材背后的"意义"。
5. 严禁私自保留、摘抄、收藏任何来自使徒的文本、符号。任何素材完成取证后，按分级判定，高危素材直接销毁。
6. 外勤执行任务，优先依靠战术与枪械压制狂暴畸变体。不要试图和求知畸变者（使徒）长时间辩论、交流理念。对话时间越久，认知被渗透风险越高。

## 第二部分：思维约束守则（最核心，心理锚定条款）

1. **禁止主动思考禁忌问题**
   不要去思索所谓更高维度、世界底层真相、畸变低语传达的启示。认知污染会借由你的思考扎根。当大脑产生这类念头，立刻强制切换到具象、琐碎的现实事务：清点装备、核对人员名单、检查弹匣。
2. **警惕"通透感"幻觉**
   如果你产生感受：以前的想法狭隘，现在看懂了世界，内心平静释然。立刻上报。这不是顿悟，是认知偏移早期征兆。
3. **不美化、不共情畸变理念**
   不要试图理解使徒追寻的"真理"。哪怕对方逻辑自洽、言语温和，这套认知体系本身就是污染源。共情即是被侵染的第一步。
4. **建立固定思维锚点**
   当感知到低语、意识开始涣散时，在内心反复默念预设锚定语句（可选：我的职责是守护普通人，眼前的幻象并非真实，感官会欺骗我，但现实世界的规则不变），同时专注感受身体物理触感：脚下地面、手中装备重量。
5. **区分"观测"和"认同"**
   作为调查人员，你可以记录畸变者的言行、症状，但**记录不等于认同**。只客观记录现象，不要去推导、体会他们的精神体验。

## 第三部分：日常监测与分级管理守则

序调组对全员实行三级认知分级，定期心理评估。

- **纯白级**：未接触高危污染源，无异常感知。主要承担外勤作战、后勤、物资保障，禁止进入高危素材库房、重度污染现场。一旦接触污染环境，认知等级自动降级。
- **浅染级**：曾接触污染源，出现过短暂幻听、感知扭曲，但无认知认同。禁止独立查阅高危素材，只能在纯白人员陪同下执行低风险现场任务，定期复测认知状态。任务量强制限制，安排充足休息。
- **抗性级**：多次暴露在污染环境，依旧保持认知稳定，能识别隐性认知偏移。是唯一可以进入重度污染现场、查阅最高等级畸变素材的人员。**但抗性不是免疫，污染依旧会缓慢累积。**必须接受高频心理筛查，强制轮休。

**重要规定**：任何人员不得主动申请升级抗性等级。等级由评估小组判定。

## 第四部分：异常上报规则

出现以下任意一种情况，24小时内必须上报，不得隐瞒：

1. 反复听见旁人无法听见的低语；
2. 看见光影扭曲、不存在的符号，且无法确认是疲劳造成；
3. 不自觉反复回想畸变素材内容；
4. 对现有秩序、自身职责产生持续怀疑；
5. 内心产生想法：使徒或许并非恶人，他们追寻的东西有道理；
6. 发现身边同事出现上述任意症状。

隐瞒认知偏移，不仅危及自身，更会缓慢污染整个团队。隐性同化者外表、行为完全正常，很难肉眼分辨。上报不是示弱，是保护整个队伍。

## 第五部分：底线声明（结尾锚定）

这套守则只能延缓认知侵蚀，**不能彻底隔绝污染**。

长期持续接触畸变信息，即便是抗性级人员，也终将抵达认知偏移临界点。我们所做一切，只是拉长人类文明喘息的时间。

武器守住肉体，守则守住思想。
