# AVG 无限重生——内容生产与垂直切片

版本：v0.1  
状态：待核心机制确定后执行

## 1. 当前原则
不要一开始制作完整游戏。先用小规模内容验证核心循环。

## 2. 垂直切片目标
建议包含：
- 少量地点。
- 少量 NPC。
- 少量剧情节点。
- 约 3 轮循环。
- 至少一次“新信息 → 新选项 → 新路线”。
- 至少一次死亡 → 回溯。
- 至少一种减少重复内容的方法。

## 3. 验证问题
- 重生是否真的让玩家产生探索欲？
- 玩家是否能理解信息的价值？
- 新选项是否有发现感？
- 重复内容是否令人疲劳？
- 分支汇流是否自然？
- 节点回溯是否有意义？

## 4. 暂不追求
- 大量文本。
- 大量美术资源。
- 完整世界观。
- 完整 UI。
- 最终演出品质。
