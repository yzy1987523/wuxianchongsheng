# AVG 无限重生——剧情与分支系统

版本：v0.1  
状态：重点研究中

## 1. 当前已确定
玩家通过选择产生不同结果；死亡后获得新的信息；新信息可能让过去的节点出现新的选项，从而进入新的剧情分支。

## 2. 最大风险：分支爆炸
不能简单采用：
“每个新发现 → 一条完整新剧情树”。

原因：
- 内容规模会快速增长。
- 大量路线会产生重复文本。
- 独立开发成本不可控。
- 测试与维护困难。

## 3. 当前倾向：剧情图
倾向采用“分支 → 差异 → 汇流”的结构，而不是无限树状扩张。

## 4. Knowledge / Flag
新信息可以改变已有节点的条件，而不必复制整个剧情。

## 5. 待解决
- 分支何时汇流。
- 什么信息值得成为永久 Knowledge。
- Flag 与 Knowledge 的区别。
- 一个节点允许多少分支。
- 如何表示条件组合。
- 如何防止剧情状态互相冲突。
- 如何让玩家理解“为什么现在出现了新选项”。
- 如何制作剧情编辑工具。

## 6. 暂不制作
完整世界观、角色表、正式长篇剧情，等核心结构稳定后再进入。
