# AVG 无限重生——技术架构（Godot）

版本：v0.1  
状态：设计中

## 1. 已确定
开发引擎：Godot。

## 2. 暂定模块
- Dialogue：对话、选项、文本。
- Event：事件触发。
- Story：剧情逻辑。
- Loop：死亡、重生、循环。
- State：玩家与世界状态。
- Save：永久进度保存。

## 3. 数据驱动方向
倾向不要把大量剧情逻辑硬编码在场景脚本中，而是使用结构化数据描述：
- 节点
- 对话
- 选项
- 条件
- 结果
- 状态变化

## 4. 待解决
- 剧情数据格式：JSON / Resource / 自定义格式。
- 节点 ID 规则。
- Choice / Condition / Effect 数据结构。
- Save 数据结构。
- 版本兼容。
- 编辑剧情的工作流。
- 调试工具。
- 如何可视化剧情图。
- 如何快速定位死循环或无法到达的节点。

## 5. 开发顺序候选
1. 最小对话系统。
2. 选择系统。
3. Flag / Knowledge。
4. 事件系统。
5. 死亡与重生。
6. 存档。
7. 节点回溯。
8. 剧情图工具。
