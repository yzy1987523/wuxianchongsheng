# AVG 无限重生——重生与回溯系统

版本：v0.1  
状态：设计中

## 1. 当前已确定
- 主角可以无限重生。
- 死亡后回到特定时间节点。
- 重生后的玩家拥有上一轮获得的部分永久信息/进展。

## 2. 暂定方向：节点回溯
玩家可以回到已经探索过的指定节点，以减少重新操作的成本。

## 3. 核心问题

### 3.1 什么是节点？
待定义：
- 时间？
- 地点？
- 剧情状态？
- 玩家状态？
- 世界状态？
- 事件状态？

### 3.2 回溯保存什么？
待定义：
- 玩家 Knowledge。
- 已解锁选项。
- 已发现地点。
- 事件 Flag。
- 能力。
- 物品。
- NPC 状态。

### 3.3 如何减少重复？
待研究：
- 跳过已观看剧情。
- 已知路线快速推进。
- 条件满足后自动触发。
- 捷径。
- 直接选择已验证结果。

## 4. 永久状态与循环状态

### 永久状态（候选）
- Knowledge / 信息。
- 已发现内容。
- 部分能力。
- 部分剧情 Flag。

### 循环状态（候选）
- 当前时间。
- 临时物品。
- 当轮 NPC 状态。
- 当轮事件进度。

最终边界尚未确定。

## 5. 待解决
- 重生触发条件。
- 重生位置。
- 节点生成规则。
- 节点数量限制。
- 是否允许任意回溯。
- 回溯是否有成本。
- 回溯后是否允许改变已经发生的事件。
