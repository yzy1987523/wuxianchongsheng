# AVG 无限重生——核心玩法

版本：v0.1  
状态：设计中

## 1. 当前已确定
- 游戏类型：AVG / 剧情探索。
- 主角可以无限重生。
- 死亡后回到特定时间节点。
- 死亡是核心循环，而非单纯 Game Over。
- 玩家通过每次循环获得新的信息与认知。
- 新认知能够改变后续选择，并打开新的剧情内容。

## 2. 核心循环
探索 → 对话/调查 → 选择 → 结果 → 死亡 → 重生 → 利用新认知改变选择 → 探索新的内容。

## 3. 当前体验目标
玩家应该产生“我这次知道得更多了，所以我能做得不一样”的感觉。

## 4. 待解决问题
- 玩家一次循环的合理长度。
- 什么行为属于探索，什么行为属于剧情推进。
- 玩家如何明确感受到自己的认知成长。
- 如何避免重复内容造成疲劳。
- 是否存在非死亡的循环结束方式。

## 5. 暂时不解决
- 完整世界观。
- 大量角色。
- 完整剧情文本。
- 美术与演出细节。
