## 使用规则

聊天用于探索和讨论；文档用于沉淀当前结论。

状态标记：
- 🟢 已确定
- 🟡 暂定
- 🔴 冲突 / 待解决
- ⚪ 暂时不处理

重要设计发生改变时：
1. 修改对应专题文档。
2. 更新项目总览中的相关状态。
3. 在 `99_设计变更记录.md` 留下记录。
